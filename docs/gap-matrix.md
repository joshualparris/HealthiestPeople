# Comprehensive profile gap matrix

_Last audited: 20 September 2026._

This is the working completeness map for every named profile in the repository.

A blank cell is **not** assumed normal. Each gap is classified so future research can distinguish "not yet searched" from "not publicly available".

## Status key

- **OPEN-NUMERIC** — exact values are publicly accessible in text/table form.
- **OPEN-VISUAL** — public, but mainly in images/charts/video frames.
- **GATED** — subscription/Patreon/member access.
- **WITHHELD** — subject explicitly chose not to release the result.
- **COHORT-ONLY** — data exist in research but are not individually attributable to the named person.
- **SUMMARY-ONLY** — only percentiles/narrative summaries are public.
- **NOT-LOCATED** — searched but no reliable public value located yet.
- **N/A / not appropriate** — not a meaningful comparison or not ethically appropriate to infer.

## Priority 1 — life context

For each person document, where publicly available and relevant:

- [ ] occupation/workload during measurement period
- [ ] family/caring context
- [ ] financial/time resources
- [ ] whether health optimisation is a full-time activity
- [ ] major stressors
- [ ] social/community practices
- [ ] travel/work constraints
- [ ] changes in routine over time

This matters because a protocol requiring several hours per day and a medical team is not directly comparable with a protocol maintained while working a normal full-time job.

## Priority 5 — cost and transferability

For every recurring behaviour/intervention, classify:

| Tier | Definition |
|---|---|
| **Free** | no meaningful incremental cost |
| **Low** | ordinary household/grocery/recreation spend |
| **Moderate** | optional consumer equipment/testing |
| **High** | specialist/private testing, premium devices, repeated scans |
| **Very high / experimental** | concierge medicine, advanced procedures, experimental therapies |

Also estimate:

- hours/week
- setup burden
- whether it can involve children/family
- whether it requires a gym
- whether it requires medical supervision
- whether there is good evidence of meaningful benefit

## Things this project will not do

- treat "biological age" as literal age
- infer normal values from missing data
- confuse elite athletic performance with absence of disease
- treat self-published measurements as peer-reviewed evidence
- assume expensive interventions caused favourable outcomes
- recommend prescription drugs, peptides or experimental treatments from influencer protocols
- frame normal family/work constraints as a failure of discipline
